# Archived Public Release Assets

This directory is retained only to preserve historical `/releases/...` URLs that may still exist in bookmarks, embeds, or external links.

It is **not** a release catalog, import source, or source of truth.

- Release metadata lives in Supabase `releases` and `tracks`.
- Media lives in `media_assets` and `media_links`, backed by the `public-media` bucket.
- New releases and media must be created through Ensemblis/Studio, not by adding folders here.
- Existing release folders are frozen compatibility assets and should not be edited or copied for new releases.

Do not add new release manifests or templates to this directory.

See [`docs/catalog-architecture.md`](../../docs/catalog-architecture.md) for the canonical model and publishing flow.
